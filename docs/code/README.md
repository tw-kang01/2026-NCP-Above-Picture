# 버튼에서 저장까지 코드 따라 읽기

메인 README의 로컬 실행과 기록 저장을 마쳤다면, 이제 방금 누른 **답변 보내기**가 어떤 코드로 이어지는지 읽어 보겠습니다. 이 안내는 코드를 처음 읽는 사람을 위해 한 번의 요청을 세 문서로 나눴습니다. 처음에는 파일 전체를 이해하려 하기보다 입력값이 다음 함수로 넘어가는 지점을 따라가세요.

실습에서는 '발표를 마치고 동네 카페에서 쉬었다'라는 가상의 기억을 계속 사용합니다. 브라우저의 답변 한 문장이 JSON 요청이 되고 서버에서 검사·저장된 뒤 다시 화면에 나타나는 과정을 봅니다. 그림에 나오는 파일은 각 문서에서 직접 열어 볼 수 있습니다.

```text
브라우저 입력과 화면 상태
  → JSON 요청을 만드는 통신 파일
  → URL에 대응하는 서버 입구
  → 소유자·입력·현재 단계 검사
  → 다음 질문과 기록 저장
  → 응답으로 화면 갱신
```

## 읽기 전에 준비할 것

[메인 README](../../README.md)의 1~2장을 따라 내 PC에서 demo 앱을 켜고 테스트 기록을 저장해 둡니다. 아직 실행하지 않았다면 그곳에서 먼저 앱을 사용해 보세요. 이 코드 안내를 읽으려고 NCP 서버나 유료 API 키를 준비할 필요는 없습니다.

개발 서버는 PowerShell에서 실행한 상태로 둡니다. 웹브라우저에서는 `http://127.0.0.1:3000`을 열고, 코드 편집기에서는 `package.json`이 있는 프로젝트 폴더를 엽니다. 브라우저로 확인하는 부분과 파일을 읽는 부분을 번갈아 진행합니다. JavaScript·JSON 예시는 읽는 연습이므로 PowerShell에 입력하지 않습니다.

실습에는 가상의 답변과 공개해도 되는 테스트 이미지를 사용하세요. 개발자 도구의 요청·응답에는 실제 답변과 쿠키가 보일 수 있습니다. 이 화면이나 로그를 공유할 때는 개인 내용·식별값·키를 제외합니다. 예시에 쓸 수 있는 이미지는 [test-photo.png](../../scripts/fixtures/test-photo.png)입니다.
