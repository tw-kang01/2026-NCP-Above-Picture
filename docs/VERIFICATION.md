# 검증 기록과 실제 운영 확인 범위

기준일: 2026-10-29. 설계·로컬 검사·실제 클라우드 확인을 구분합니다.
공개본에는 개인 사진·일기·키·실제 인프라 식별자를 넣지 않습니다. 과거 화면과 발표 파일도 공개 자료로 그대로 옮기지 않았습니다.

## 1. 공개 정리 과정에서 확인한 결과

| 항목 | 결과 | 범위 |
|---|---|---|
| npm test | 질문 형식 보완 후 최종 오프라인·모의 검사 15개 성공 | 외부 유료 요청 없음 |
| npm run build | 성공 | 실행용 Next.js 빌드 |
| npm run test:app | 질문 형식 보완 후 최종 HTTP 21개 시나리오 성공 | 격리 demo 서버·데이터 |
| Bash 구문 | 설치·HTTPS 스크립트 통과 | 실제 설치·발급 실행은 아님 |
| PowerShell 파싱 | 패키징 스크립트 통과 | 구문 확인 |
| Postman JSON | 파싱 성공 | 실제 계정 API 성공은 아님 |

질문에 마크다운 라벨·설계 해설이 섞이는 보고를 반영해 question-format.js와 질문 생성·표시 처리를 보완했습니다.
그 뒤 최종 검사 15개, 운영 빌드, HTTP 21개 시나리오를 모두 다시 통과했습니다.
원래 개발 폴더에도 해당 질문 수정을 동기화하고 15개 검사를 통과했습니다. NCP 운영 서버에 배포한 것은 아닙니다.
새 검사에서는 질문 JSON·알려진 포장·설계 설명 제거, 다중 질문·잘림·부적절한 응답, 기존 기록 표시와 원문 보존을 확인합니다.
Windows 환경의 샌드박스·junction·loopback 제한을 처리한 실행에서 확인했으며 이 제한을 앱 오류와 혼동하지 않습니다.

## 2. 자동 검사가 확인하는 것

오프라인·모의 검사는 입력·이미지 형식·안전한 오류·CLOVA 요청 필드와 응답 형식을 통제해서 확인합니다.
사진 서명 URL, 관찰과 글쓰기 입력 분리, 반복 질문, 작성·검토, 원문 대안 등의 계약을 확인합니다.
실제 모델이 좋은 한국어 문장을 쓰는지, 계정에서 모델에 접근할 수 있는지를 모의 응답으로 증명할 수는 없습니다.

HTTP 검사는 실제 로컬 서버에 요청합니다. demo 모드와 별도 포트·무작위 데이터 경로를 사용합니다.
기록 생성·사진·질문 수·답변·초안·재작성·버전·다른 소유자 차단·삭제를 확인합니다.
검사가 만든 기록만 정리하며 운영 기록을 삭제하지 않습니다.

## 3. 과거 개발 과정의 확인

2026-10-23에는 로컬 MVP의 빌드, 당시 15개 HTTP 검사와 브라우저 사용 흐름을 확인했습니다.
사진 선택→질문 답변→초안→수정 저장→재조회, PC·모바일 크기의 배치를 살폈습니다.
이는 당시 버전의 확인이며 최신 모델 출력이나 실제 휴대전화 전체 검증으로 확대하지 않습니다.

2026-10-28에는 설치·API·코드·NCP 설명과 발표 구조를 정리했습니다.
문서 정리가 실제 NCP 실행 성공을 뜻하지는 않습니다.

2026-10-29의 이전 대화에서는 실제 NCP DB의 SELECT 1 성공, photo-memory·nginx active, 서버 내부 앱·프록시 HTTP 200, 공인 HTTP 응답을 확인했습니다.
당시 사진 업로드·질문과 초안의 품질 문제도 보고되어 개선을 진행했습니다.
이 증거를 최신 HCX-007 권한·작문 품질·IP 인증서 발급·갱신 완료로 설명하지 않습니다.

## 4. 아직 실서버에서 확인할 것

- 새 공개 코드가 운영 서버에 적용됐는지
- HCX-005와 HCX-007의 현재 계정 접근 권한
- 실제 사진 저장·읽기·삭제와 서명 URL 접근
- 새 질문의 자연스러움·중복·불필요한 설명 제거
- 실제 긴 답변의 작성·검토·원문 보존 품질
- 초안 재작성 후 버전과 저장 동작
- HTTPS 인증서 발급·HTTP 이동·신뢰 검증
- 갱신 타이머와 갱신 dry-run
- PC 종료 뒤 외부 기기 접속과 서버 재부팅 후 자동 실행

## 5. 다시 검사하는 명령

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run test:app
npm.cmd run check:publish
```

실제 모델 점검은 NCP에서 별도로 의도하여 실행합니다.

```bash
node --env-file=.env.local scripts/check-ncp-ai.mjs
```

이 요청은 실제 계정 사용량을 소비할 수 있습니다. 짧은 연결 확인이며 전체 사진·일기 품질 평가는 아닙니다.
공개 전 검사·패키징 결과와 최종 커밋은 현재 저장소의 최종 작업 결과를 기준으로 기록합니다.
